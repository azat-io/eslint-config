# Приложение A — полная инвентаризация правил

Сгенерировано автоматически из `@azat-io/eslint-config` v2.99.0 (`dist`,
собранный из `HEAD dd0adaf`): для каждого объекта конфигурации выведены все
правила, а применимость определена через `ESLint#calculateConfigForFile()` на
представительных файлах при **всех** включённых опциях. Колонки TSX/JSX получены
на копии `dist` с исправленными React-правилами, потому что исходная версия
падает (P0-1 в отчёте).

Обозначения: **fix** — есть автофикс; **sugg** — только suggestions; **typed** —
нужна type information; ❌ — правила **нет** в установленном плагине, ESLint
бросает `TypeError`; ⛔ — выключено явно. Колонка «Применяется»: JS =
`.js/.cjs/.mjs`, TS = `.ts/.cts/.mts/.d.ts`, Test = `*.test.ts` / `test/*.ts`
(vitest), TSX/JSX при `react`/`qwik`, PKG = `package.json`.
